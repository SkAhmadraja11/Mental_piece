# Mental Piece 💖

> *"Not the fast, texting-while-walking kind of sorry. The proper kind, with graphs, dates, and memories."*

An ultra-personalized, interactive romantic apology and love story web application crafted with high-end aesthetic UI/UX, playful interactive gags, and real-time relationship milestones.

---

## ✨ Features

- **Gatekeeper Minigame:** A playful entrance quiz and heart-popping minigame before unlocking the site.
- **The Milestones of Us (Interactive Timeline):**
  - **21 Jan 2023:** The Day Our Orbits Collided (First Met)
  - **14 Feb 2023:** Heart on the Line (Valentine's Proposal)
  - **21 Feb 2023:** The First Reunion (Travelling to meet her)
  - **Today & Forever:** Over 1,300+ days and counting.
- **Calibrated Love Counter:** Live ticking counter displaying Days, Hours, Minutes, Seconds, and estimated total heartbeats dedicated to her, with quick-switch tabs for each milestone.
- **Ambient Romantic Music & Controls:** Procedural piano lofi melody via Web Audio API paired with a retro spinning vinyl record widget and Candlelight Midnight Mode switch.
- **Draggable Polaroid Scrapbook:** Interactive retro polaroid snapshots with washi tape, 3D tilt, and flip-to-read secret handwritten notes.
- **The Apology Coupon Book:** Redeemable vouchers (e.g., Win 1 Argument, Late-Night Ice Cream Run) that stamp with golden wax seals upon claim.
- **Playfully Irritating Gags:** 
  - Biometric Anger Scanner pad with funny diagnoses (94% Hangry).
  - Teleporting "Actually, yours" button with teasing dialogue.
  - Prank "No" button that transforms into *"Yes, but with extra snacks 🍟"*.
  - Hilarious contract clauses (*The Cold Feet Doctrine* & *The Closet Paradox*).

## 🚀 Deployment (GitHub Pages)

This project is built with vanilla HTML, CSS, and JavaScript with zero external build dependencies:

1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Source**, select `Deploy from a branch`.
4. Choose the `main` branch and `/ (root)` folder, then click **Save**.
5. Your interactive site will be live instantly!
